Switching provider

The demo picks the provider from the URL, but a real project names one in its settings:

CAPTCHA_KIT = {
        "DEFAULT": "turnstile",
        "PROVIDERS": {
            "turnstile": {
                "SITE_KEY": env("TURNSTILE_SITE_KEY"),
                "SECRET_KEY": env("TURNSTILE_SECRET_KEY"),
            },
        },
    }

Changing DEFAULT is the whole migration. Try it by editing CAPTCHA_DRIVER in .env, then reload the form mixin page.
